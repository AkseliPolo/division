The application

A simple Node.js project that exports a divide(a, b) function in src/calculator.js. Before dividing, the function validates its input and throws TypeError if either argument is not a number or is NaN, and RangeError if the divisor is zero. src/index.js runs the function and prints the result. Tests are written with Jest and run with npm test.
